== Tasks

== Task 0

Enter a `busybox` container. Create a file and exit the container. Stop the container. Restart the container and try reading the file.

== Task 1

Create an `alpine` container: install bash and SDK. Create a `Hello World` program. Copy the program into the container (use `docker cp` command  --  it works the same as `scp`). Compile and run the program. Copy the compiled binary into the host system and try running it.

== Task 2

Create an image which can be started in a detached mode without `-it` option. Create the container and enter it in two different terminals. Check that the can observe each other's changes.

== Task 3

Create a `Hello World` program. Use multi-stage and `scratch` to create an image with a single executable file.

TIP: Use musl and `-static`

TIP: Use Graal VM.
