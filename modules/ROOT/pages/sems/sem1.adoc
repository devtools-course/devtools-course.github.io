== Tasks

== Part 0

Create a repo on GitLab (with `README.md`). Clone it locally. Commit some changes to the `README.md` file *on GitLab*. Now pull them into your local repo.

== Part 1

Create a repo on GitLab (with `README.md`). Create an empty local repository. Create locally and commit a `file.txt` file to the `main` branch. Now synchronise both repos.

== Part 2

Create a repo on GitLab (with `README.md`). Change `README.md` and commit it *on GitLab*. Now clone it. Reset the changes and commit the updates.

== Part 3

Use one of the previous repos. Add https://github.com/devtools-course/task-regex[this repository] as a remote. Apply some changes to its `README.adoc` and push the changes to the `origin`.

== Part 4

Use the previous repo. Move your `HEAD` to the detached state. Apply and commit some changes. Create a branch and push it.
