== Tasks

=== Task 0

Use macros to implement custom casserts:

[,cpp]
----
int foo() { return 1; }
int y = 2;

int main() {
    assert(foo() > y);
}
----

Output must be:
[,console]
----
$ ./a.out
a.out: a.cc:7: int main(): Assertion `foo() > y' failed.
----

=== Task 1

Update the `assert` macro so that it has two options:

- `assert(_EXPR_)`  --  has the same behaviour
- `assert(_EXPR_, _MSG_)`  --  add a custom message `_MSG_`

When the sources are compiled with `-DNDEBUG`, all asserts must be ignored, e.g. the code below must not print anything:

[,cpp]
----
int foo() { std::cout << "Hi"; return 1; }
int y = 2;

int main() {
    assert(foo() > y);
}
----

=== Task 2

Try compiling the code below with `-O0` .. `-O3`. What happens?

[,cpp]
----
int i = 1;
while (i > 0) { i++; }
std::cout << "hi\n";
----
