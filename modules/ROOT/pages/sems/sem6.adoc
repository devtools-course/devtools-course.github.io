== Tasks

To start the ssh server run:

[,console]
----
$ docker run --rm -d -p 22:22 ghcr.io/devtools-course/task-ssh:latest
----

Now you can access the server via `localhost`.

== Part 0

Do the xref:tasks/task-ftp.adoc[FTP assignment].

== Part 1

Establish a connection to the server. Run `echo 'Hello World!'` using ssh.

== Part 2

Establish a connection to the server. Create a file `out.txt` that contains `42` using ssh.

== Part 3

Create a man page for the `cow` utility from the xref:tasks/task-shell-setup.adoc[] assignment.
