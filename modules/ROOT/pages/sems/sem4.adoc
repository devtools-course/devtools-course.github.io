== Useful pipeline commands

* `cat _FILENAME_...`  --  concatenate files' content
* `head -n _LINES_`  --  print first `_LINES_` lines
* `tail -n _LINES_`  --  print last `_LINES_` lines

image::barsik.png[]


* `rev`  --  revert
* `cut -f<N> -d<D>`  --  split by the delimiter `D` and select the field `N`
* `sort [-knr]`  --  sort the lines
** `-k _N_`  --  sort by `_N_`{empty}'s key
** `-n`  --  sort as numbers (_alphabetic order_ is the default one)
** `-r`  --  descending
* `tr _FROM_ _TO_`  --  replace
* `tr -d _CHAR_`  --  remove
* `uniq`  --  deal with duplications
* `xargs`  --  move stdin to argv
* `tee _FILENAME_`  --  log to `FILENAME`

=== Part 2

Create a script `part-2.sh` which has these options:

* `-f|--force`
* `-i|--input _INPUT_`
* `-rev|--reverse`

It prints `_INPUT_`{empty}'s characters separated by space. When the `force` option is on, the characters must be printed one per line. When the `rev` option is on, the characters must be printed in the reverse order. When no `input` is provided, the script must exit with a code `13`.
